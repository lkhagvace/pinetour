Tailwind — 10 дасгал

Зураг + дизайнерын CSS өгөгдсөн. Түүнийг Tailwind class болгож хөрвүүл.

ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html үүсгэ, доорх кодыг хуул. Tailwind-ийн <script> мөр байгаа эсэхийг шалга.
  2. Дасгал бүрийн ЭХЛЭХ КОД-ыг body дотор хуул. Тэнд нэг ч class алга — class нэмэх нь чиний ажил.
  3. ①②③ дугаар = ЗАГВАР хэсгийн элемент. Дизайнерын өгсөн CSS-ийг Tailwind class болгож бич (доорх хүснэгт).
  4. Live Server-ээр нээгээд ЗОРИЛГО зурагтай харьцуул. Яг адилхан болтол засна.
