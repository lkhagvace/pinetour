ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html, script.js гэсэн хоёр файл үүсгэ.
  2. index.html-д доорх кодыг хуул. <script> нь body-гийн хамгийн доор байна.
  3. Дасгал бүрийг script.js-д бич. Дараагийн дасгал руу шилжихдээ өмнөхөө /* */-аар comment болго.
  4. Console-оо нээ: Cmd + Option + J. Алдаа гарвал улаан мөрийг унш.
<!doctype html>
<html lang="mn">
  <head>
    <meta charset="UTF-8" />
    <title>JS дасгал</title>
  </head>
  <body>

  </body>
</html>
ДАСГАЛ 1

Өгүүлбэрийн шинжилгээ 📝

Өгүүлбэрт хэдэн үг байгааг, хамгийн урт үгийг (тэнцүү бол эхнийхийг) үсгийн тоотой нь, target үг хэдэн удаа орсныг хэвлэ. Өгүүлбэрийн хоёр талд зай байж болно.

ЭХЛЭХ КОД — хуулж ав

const text = "Монгол хэл бол маш баян хэл";
const target = "хэл";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 📝 6 үг› 📏 Хамгийн урт: Монгол (6 үсэг)› 🔁 «хэл» 2 удаа

ХЭРЭВ const text = " нэг хоёр гурав хоёр "; БОЛ

console› 📝 4 үг› 📏 Хамгийн урт: гурав (5 үсэг)› 🔁 «хэл» 0 удаа

💡 trim().split(" ") → үгсийн массив; үгийн тоо = массивын length. Хамгийн уртыг эхний үгээс эхэлж, words[i].length-ээр харьцуул. target-тэй тэнцэх үг бүрт тоолуур нэм.

Хэрэглэх: trim · split · length · for · if · ===

ДАСГАЛ 2

Нууц үгийн хүч 🔐

Нууц үгийг 4 дүрмээр шалгаад мөр бүрт ✅ / ❌ хэвлэ: 8+ тэмдэгт, тоо орсон, том үсэг орсон, нэвтрэх нэр (жижиг үсгээр ч) ороогүй. Төгсгөлд: 4 дүрэм бүгд бол «💪 Хүчтэй», 2–3 бол «🙂 Дунд», 0–1 бол «😟 Сул».

ЭХЛЭХ КОД — хуулж ав

const password = "Pinecone2026";
const username = "bat";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ✅ 8+ тэмдэгт› ✅ Тоо орсон› ✅ Том үсэг орсон› ✅ Нэвтрэх нэр ороогүй› 💪 Хүчтэй

ХЭРЭВ const password = "bat12345"; БОЛ

console› ✅ 8+ тэмдэгт› ✅ Тоо орсон› ❌ Том үсэг алга› ❌ Нэвтрэх нэрээ бүү ашигла› 🙂 Дунд

ХЭРЭВ const password = "abc"; БОЛ

console› ❌ 8-аас богино› ❌ Тоо алга› ❌ Том үсэг алга› ✅ Нэвтрэх нэр ороогүй› 😟 Сул

💡 Үсэг бүрийг password[i]-ээр давтан шалга. Тоо мөн эсэх: "0123456789".includes(үсэг). Том үсэг мөн эсэх: үсэг !== үсэг.toLowerCase(). Хэдэн дүрэм биелснийг тоолуураар тоол.

Хэрэглэх: length · for · password[i] · includes · toLowerCase · тоолуур

ДАСГАЛ 3

Сагсны командууд 🤖

commands массивын команд бүрийг дарааллаар нь гүйцэтгэ. «add 🍎» — сагсанд байхгүй бол нэм, байвал анхааруулга. «remove 🥛» — байвал устга, байхгүй бол түүнийг хэвлэ. Төгсгөлд нь сагсыг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const commands = ["add 🍎", "add 🥛", "add 🍎", "remove 🥛", "remove 🧀", "add 🍞"];
const cart = [];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ➕ 🍎› ➕ 🥛› ⚠️ 🍎 сагсанд байна› ➖ 🥛› 😶 🧀 сагсанд алга› ➕ 🍞› 🛒 🍎 🍞

💡 Команд бүрийг split(" ") → [үйлдэл, бараа]. Үйлдэл "add" бол includes → push. "remove" бол indexOf → -1 биш бол splice.

Хэрэглэх: for · split · includes · push · indexOf · splice · join

ДАСГАЛ 4

Ангийн жагсаалт цэгцлэх 👥

Багш нэрсийг янз бүрээр бичжээ. Нэр бүрийн зайг арилгаад, эхний үсгийг том, бусдыг жижиг болго. Давхардсан нэрийг НЭГ л удаа үлдээ. Шинэ массивт цуглуулаад тоо, нэрсийг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const raw = ["  бат", "САРАА ", "бат", "ану", " Сараа", "БОЛД"];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 👥 4 сурагч: Бат, Сараа, Ану, Болд

💡 Хоосон names массиваас эхэл. Нэр бүрт: trim → эхний үсэг toUpperCase() + slice(1).toLowerCase(). names.includes(нэр) биш бол л push.

Хэрэглэх: for · trim · [0] · toUpperCase · slice · toLowerCase · includes · push · join

ДАСГАЛ 5

Спам цэвэрлэх 🎰

«🎰» орсон зурвас бүрийг confirm-оор асуугаад OK бол устга, Cancel бол үлдээ. СҮҮЛЭЭС нь эхэлж шалга. Асуух текст: «Спам устгах уу: «зурвас»?». Төгсгөлд хэдэн зурвас үлдсэн, юу юу үлдсэнийг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const messages = ["Сайн уу 👋", "🎰 Шагнал авах", "🎰 Үнэгүй утас", "Маргааш уулзах уу?"];

CONFIRM → OK, OK ДАРВАЛ

console› 🗑 Устгалаа: 🎰 Үнэгүй утас› 🗑 Устгалаа: 🎰 Шагнал авах› 📬 2 зурвас: Сайн уу 👋 · Маргааш уулзах уу?

CONFIRM → OK, CANCEL ДАРВАЛ

console› 🗑 Устгалаа: 🎰 Үнэгүй утас› ↩️ Үлдээлээ: 🎰 Шагнал авах› 📬 3 зурвас: Сайн уу 👋 · 🎰 Шагнал авах · Маргааш уулзах уу?

💡 Яагаад сүүлээс вэ? splice-ийн дараа ард байсан зурвасууд урагшилдаг — урагшаа давтвал хоёр спам зэрэгцсэн үед нэгийг нь алгасна. i = messages.length - 1-ээс эхэлж i-- хий.

Хэрэглэх: for i-- · includes · confirm · splice · join
