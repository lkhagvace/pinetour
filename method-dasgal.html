Текст ба массивын method — 10 дасгал

trim · toLowerCase · includes · slice · split · replace · push · pop · indexOf · join · splice · confirm

ЭХЛЭХ

  1. Шинэ хавтас нээгээд index.html, script.js гэсэн хоёр файл үүсгэ.
  2. index.html-д доорх кодыг хуул. <script> нь body-гийн хамгийн доор байна.
  3. Дасгал бүрийг script.js-д бич. Дараагийн дасгал руу шилжихдээ өмнөхөө /* */-аар comment болго.
  4. Console-оо нээ: Cmd + Option + J. Алдаа гарвал улаан мөрийг унш.
<!doctype html>
<html lang="mn">
  <head>
    <meta charset="UTF-8" />
    <title>JS дасгал</title>
  </head>
  <body>
    <h1>JS дасгал</h1>

    <script src="script.js"></script>
  </body>
</html>
ДАСГАЛ 1

Хэрэглэгчийн нэр цэвэрлэх 🧼

Хэрэглэгч нэрээ зайтай, том жижиг үсэг холилдуулж бичжээ. Хоёр талын зайг арилгаад бүгдийг жижиг үсэг болгож хэвлэ. Дараа нь хэдэн тэмдэгттэйг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const raw = "   BaT_ErDeNe   ";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› bat_erdene› 10 тэмдэгт

ХЭРЭВ const raw = " SARAA "; БОЛ

console› saraa› 5 тэмдэгт

💡 Гинжээр холбож болно: raw.trim().toLowerCase(). Тэмдэгтийн тоог цэвэрлэсэн текстээс (зайгүй) ав.

Хэрэглэх: trim · toLowerCase · length

ДАСГАЛ 2

Имэйл шалгах 📧

Имэйлд «@» болон «.» хоёулаа байвал «✅ Зөв имэйл», аль нэг нь дутуу бол «❌ Имэйл буруу байна».

ЭХЛЭХ КОД — хуулж ав

const email = "bat@gmail.com";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ✅ Зөв имэйл

ХЭРЭВ const email = "bat.gmail.com"; БОЛ

console› ❌ Имэйл буруу байна

ХЭРЭВ const email = "bat@gmailcom"; БОЛ

console› ❌ Имэйл буруу байна

💡 email.includes("@") нь true / false буцаана. Хоёр шалгалтыг && -ээр холбо.

Хэрэглэх: includes · && · if / else

ДАСГАЛ 3

Утасны дугаар нуух 📱

Баталгаажуулах код илгээхдээ дугаарын эхний 4 оронг үлдээгээд, үлдсэнийг «****» болгоно. Дугаар 8 оронтой биш бол анхааруулга хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const phone = "99112233";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 📱 9911****

ХЭРЭВ const phone = "88001122"; БОЛ

console› 📱 8800****

ХЭРЭВ const phone = "9911"; БОЛ

console› ⚠️ Дугаар 8 оронтой байх ёстой

💡 Эхлээд phone.length === 8 эсэхийг шалга. slice(0, 4) нь 0, 1, 2, 3-р тэмдэгтийг авна (4 орохгүй).

Хэрэглэх: length · slice · if / else

ДАСГАЛ 4

Нэрийн эхний үсэг 🔤

Овог нэрийг эхний үсгүүдээр нь «Б.Э.» болгоно. Жижиг үсгээр бичсэн ч том үсгээр гарах ёстой.

ЭХЛЭХ КОД — хуулж ав

const fullName = "Бат Эрдэнэ";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Б.Э.

ХЭРЭВ const fullName = "сараа болд"; БОЛ

console› С.Б.

💡 split(" ") → 2 үгтэй массив. Үг бүрийн [0] үсгийг аваад toUpperCase().

Хэрэглэх: split · [0] · toUpperCase

ДАСГАЛ 5

Мессежийн загвар 💬

template доторх {name}, {time}-ийг хувьсагчдын утгаар сольж хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const template = "Сайн уу, {name}! Таны захиалга {time}-д бэлэн болно.";
const name = "Бат";
const time = "14:30";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› Сайн уу, Бат! Таны захиалга 14:30-д бэлэн болно.

ХЭРЭВ const name = "Сараа"; БОЛ

console› Сайн уу, Сараа! Таны захиалга 14:30-д бэлэн болно.

💡 replace эхний олдсоныг солиод ШИНЭ текст буцаана. Хоёр replace-ийг гинжээр холбо эсвэл хувьсагчид хадгал.

Хэрэглэх: replace · гинж

ДАСГАЛ 6

Дэлгүүрийн сагс 🛒

Сагсанд 🍞 болон 🧀 нэм. Тэгээд бодлоо өөрчилж сүүлд нэмснээ буцааж гарга. Сагсыг нэг мөрөнд, зайгаар тусгаарлан хэвлээд, хэдэн бараа байгааг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const cart = ["🍎", "🥛"];

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 🛒 🍎 🥛 🍞› 3 бараа

💡 push хоёр удаа, pop нэг удаа. Хэвлэхдээ cart.join(" ") — давталт хэрэггүй.

Хэрэглэх: push · pop · join · length

ДАСГАЛ 7

Playlist-д давхардуулахгүй 🎵

song аль хэдийн playlist-д байвал анхааруулга хэвлэ. Байхгүй бол нэмээд «нэмэгдлээ» гэж хэвлэ. Төгсгөлд нь playlist-ийг « · »-ээр хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const playlist = ["Өглөө", "Бороо", "Од"];
const song = "Бороо";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› ⚠️ «Бороо» аль хэдийн байна› 🎵 Өглөө · Бороо · Од

ХЭРЭВ const song = "Хавар"; БОЛ

console› ✅ «Хавар» нэмэгдлээ› 🎵 Өглөө · Бороо · Од · Хавар

💡 playlist.includes(song) → true бол анхааруулга, false бол push. join-ыг if / else-ийн ДАРАА нэг удаа.

Хэрэглэх: includes · push · join · if / else

ДАСГАЛ 8

Дараалал 🧾

me хүн дараалалд хэддүгээрт байгааг (1-ээс тоолно) болон өмнө нь хэдэн хүн байгааг хэвлэ. Дараалалд байхгүй бол түүнийг хэвлэ.

ЭХЛЭХ КОД — хуулж ав

const queue = ["Бат", "Сараа", "Ану", "Болд"];
const me = "Ану";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› 🧾 Ану — дугаар 3, өмнө 2 хүн

ХЭРЭВ const me = "Бат"; БОЛ

console› 🧾 Бат — дугаар 1, өмнө 0 хүн

ХЭРЭВ const me = "Тэмүүлэн"; БОЛ

console› 😶 Тэмүүлэн дараалалд алга

💡 indexOf олдохгүй бол -1 буцаана. Дугаар = индекс + 1, өмнөх хүмүүсийн тоо = индекс.

Хэрэглэх: indexOf · -1 · if / else

ДАСГАЛ 9

Хийх зүйлсээс устгах 🗑

done ажлыг жагсаалтаас олоод confirm-оор асуу. OK бол устгаад «🗑 Устгалаа», Cancel бол «↩️ Цуцаллаа». Жагсаалтад огт байхгүй бол асуухгүйгээр түүнийг хэвлэ. Төгсгөлд нь жагсаалтыг хэвлэ. Асуух текст: «Устгах уу: «⚽ Бөмбөг тоглох»?» (done-ийн утгаар).

ЭХЛЭХ КОД — хуулж ав

const todos = ["📚 Гэрийн даалгавар", "⚽ Бөмбөг тоглох", "📖 Ном унших", "🧹 Өрөө цэвэрлэх"];
const done = "⚽ Бөмбөг тоглох";

CONFIRM → OK ДАРВАЛ

console› 🗑 Устгалаа› 📝 📚 Гэрийн даалгавар · 📖 Ном унших · 🧹 Өрөө цэвэрлэх

CONFIRM → CANCEL ДАРВАЛ

console› ↩️ Цуцаллаа› 📝 📚 Гэрийн даалгавар · ⚽ Бөмбөг тоглох · 📖 Ном унших · 🧹 Өрөө цэвэрлэх

ХЭРЭВ const done = "🎬 Кино үзэх"; БОЛ

console› 😶 «🎬 Кино үзэх» жагсаалтад алга› 📝 📚 Гэрийн даалгавар · ⚽ Бөмбөг тоглох · 📖 Ном унших · 🧹 Өрөө цэвэрлэх

💡 Эхлээд indexOf: -1 бол олдоогүй. Олдвол confirm-оор асуу — confirm OK дээр true, Cancel дээр false буцаана. true бол splice(index, 1) нэгийг устгана.

Хэрэглэх: indexOf · confirm · splice · join

ДАСГАЛ 10

Hashtag үүсгэгч #️⃣

Өгүүлбэрийг hashtag болго: хоёр талын зайг арилгаад, үг бүрийн эхний үсгийг том болгож, зайгүй нийлүүлээд урд нь # тавь.

ЭХЛЭХ КОД — хуулж ав

const sentence = "  монгол улсын наадам  ";

CONSOLE ДЭЭР ГАРАХ ЁСТОЙ

console› #МонголУлсынНаадам

ХЭРЭВ const sentence = "pinecone academy bootcamp"; БОЛ

console› #PineconeAcademyBootcamp

💡 trim().split(" ") → үгсийн массив. Үг бүрт: word[0].toUpperCase() + word.slice(1). «#»-ээс эхэлсэн текстэд давталтаар залга.

Хэрэглэх: trim · split · for · [0] · toUpperCase · slice
